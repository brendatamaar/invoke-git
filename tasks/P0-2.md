# Task P0-2

## Goal

Build Prototype A in `spike-diff`: a split diff view of the two 50k-line fixtures, virtualized and syntax-highlighted, with built-in readouts so P0-4 can measure it against the Phase 0 gate.

## Backlog task number

P0-2, the second of four Phase 0 tasks (P0-1 to P0-4). It covers "Prototype A — diff view" in [the plan](../docs/PLAN.md#phase-0--gpui-spike). It is not a v0.1 backlog row.

- `crates/spike-diff/` (all of it)
- `Cargo.toml`, `Cargo.lock`
- `docs/spike-results.md` (notes only; measurement is P0-4)
- `tasks/P0-2.DONE.md`

## PRD law numbers

None. Spike code is throwaway and holds no product logic.

## Constraints

- Builds on P0-1 (branch `p0-1-spike-scaffold`, not yet merged).
- New dependencies, approved by the user: `imara-diff` (a quick line diff, spike only) and `tree-sitter` + `tree-sitter-rust` (the PRD lists tree-sitter grammars).
- Follow [the highlighting pipeline](../docs/spec/diff-engine.md#highlighting-pipeline): parse both full files in the background, then style only the visible lines plus a 200-line buffer each way, cached.
- Colours from `docs/design/tokens.json` (dark theme): `bg-panel`, `add-bg`, `remove-bg`, `add-ink`, `remove-ink`, `ink`, `ink-faint`, `line`. Syntax mapping: keyword → `accent`, string → `add-ink`, comment → `ink-faint`, type → `lane-2`, function → `lane-7`, number → `warning`.
- Code text in `code` style (13px on 20px `row-diff` rows); line numbers in `code-small`. Code text stays `ink`-family on diff backgrounds; the `+`/`−` sign and line numbers carry the change too, not colour alone.
- Release builds only for running. The agent cannot see the window; the user verifies anything visual.

## Steps

1. Load `fixtures/diff/old.rs` and `new.rs` on a background thread (paths can be overridden on the command line).
2. Compute a histogram line diff with `imara-diff` and build aligned split-view rows: context on both sides, removed lines on the left paired with added lines on the right, filler where one side is shorter.
3. Render the rows in a GPUI `uniform_list` with old/new line numbers, `+`/`−` signs and add/remove backgrounds.
4. Parse both full files with tree-sitter (Rust grammar) in the background; run the highlight query only for chunks around the visible window, cache the styled chunks, and render unstyled text until a chunk is ready.
5. Scroll with the mouse wheel and with a custom scrollbar that can be dragged end to end; clicking the track jumps there.
6. Readouts: frame interval and frame build time (last, p95, max), visible rows painted without data (must stay 0), rows painted before their highlight was ready, and first paint (data ready → first frame with content). Log a summary to stdout every 5 s and the first paint once.

## Acceptance criteria

- `cargo build --release -p spike-diff` succeeds.
- `cargo run --release -p spike-diff` shows the split diff of the fixtures with highlighting, wheel scrolling and scrollbar dragging end to end (the user verifies).
- The console prints first paint once and a stats line every 5 s.
- `cargo xtask check` passes.

## Out of scope

- Measuring against the gate and the pass/fail checklist (P0-4).
- Word-level diff, staging, unified view, hunk folding, text selection.
- Prototype B (P0-3).
