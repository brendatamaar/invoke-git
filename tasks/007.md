# Task 007

## Goal

The app window with repo tabs: open a repo, initialize one, switch and close tabs, with each tab driven by the real core and shell. This is the first screen of the app; what a tab shows inside is a placeholder until tasks 10, 11 and 18.

## Backlog task number

7 in [the plan](../docs/PLAN.md#v01-backlog): "App window, open and init repo, repo tabs". Depends on 2 (component layer) and 5 (repo discovery); also uses the file watcher (task 6) and the shell runners (tasks 4, 12).

## Files likely touched

- `Cargo.toml` (workspace member `crates/app`)
- `crates/app/**` (new binary `invoke-git`: `main`, `workspace`, `session`, `tabs`, `paths`, `persist`, `setup`)
- `crates/ui/src/{tabs,welcome,summary}.rs` (new views), `crates/ui/Cargo.toml` (depends on `invoke-core`)
- `docs/PLAN.md` (row 7), `tasks/007.DONE.md`

## PRD law numbers

None directly. It must not break law 11 (disk is truth: the session never patches state, it reads) or law 12 (writes carry what they expect): the session only passes the core's commands to the shell.

## Constraints

- Architecture rule 7: the views render state and send events. They live in `ui` and take plain data; only `app` knows `shell`.
- Rule 2: no business logic in the session. It moves events and commands between the pure core and the shell.
- Tab order, selection and duplicates are a pure model, with property tests.
- Windows: two spellings of one folder (`C:\Repo`, `c:\repo\`, `\\?\C:\Repo`) must open one tab.
- No new dependencies. A folder picker comes from GPUI's own `prompt_for_paths`.
- Tests and manual runs use fixture repos in temp folders only. `INVOKE_GIT_DATA_DIR` keeps the tab file out of the user's profile.

## Acceptance criteria

- Opening a folder that holds or is inside a repo shows a tab with its branch, tracking, phase and change counts, read through the core.
- A folder that is not a repo says so and offers "Initialize here", which runs `git init` and opens the repo.
- Opening an already open repo selects its tab.
- Tabs survive a restart (a plain text file). A folder that vanished is skipped.
- A missing or too-old git shows a blocking setup screen with the fix and a "Check again" button.
- `cargo xtask check` passes. The UI half ends with a Windows checklist in DONE.md.

## Out of scope

- Clone (task 16), the diff, status tree and graph inside a tab (tasks 10, 11, 18), branch switching, fetch and push controls.
- Window chrome and menus; icons.
