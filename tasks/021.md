# Task 021

## Goal

The pre-push review screen: the commits that would be pushed, the files they change as one combined diff or one commit at a time, "viewed" ticks, and the Push button.

## Backlog task number

21 in [the plan](../docs/PLAN.md#v01-backlog): "Pre-push review screen: outgoing commits, combined and per-commit diffs". The notes and the to-do warning of the mockup belong to task 22.

## Files likely touched

- `crates/shell/src/{outgoing,commit_detail,lib}.rs`, `crates/shell/Cargo.toml` (the `revision` feature of `gix`), `crates/shell/tests/outgoing.rs`
- `crates/app/src/{review,review_view,repo_view,sync_view}.rs`
- `docs/PLAN.md` (row 21)

## PRD law numbers

- 3 of the goals ("Review before push"); the push flow in the PRD: review, then pushing, then done or rejected and back to the review with the new outgoing set.
- Rule 4: the list is read again when the head or the upstream moves; it is never patched.
- Rule 3: reads through `gix` only; the push itself is task 17's `PushRequested`.

## Constraints

- `core` stays pure; the reading is in `shell`, the words and the state worth testing in `app::review`, the drawing in `app::review_view`. Colours and sizes from `tokens`.
- No new dependencies (a feature flag of `gix` is added, see DONE.md).
- Tests use generated repos with a local bare remote.

## Acceptance criteria

- `read_outgoing` agrees with `git rev-list @{u}..HEAD` and `git diff --name-only @{u}...HEAD` (property test), including when the remote moved, for a branch without an upstream, for a repository with no remote, for merges (listed by time), and when the list is cut at its limit.
- Unit and property tests for the title, the subtitle, the button words, the viewed ticks and the key that decides when to read again.
- A run in the real app against a local bare remote: open the review, switch to per commit, tick a file, push from it; the review then says there is nothing to push.
- `cargo xtask check`; a Windows checklist in `021.DONE.md`.

## Out of scope

- Notes, annotations and the to-do warning (task 22).
- Rename detection; binary and large-file collapsing (the viewer's own).
