# Task 008

## Goal

Create the pure `diff` crate: a line diff (histogram by default, Myers as fallback and oracle), hunk grouping with context, word-level diff inside changed line pairs, and an `apply` function, so laws 1 to 3 are testable. The data model is shaped so that line staging (task 11) and highlighting (task 9) can build on it.

## Backlog task number

8 in [the plan](../docs/PLAN.md#v01-backlog): "Diff engine: Myers + histogram, hunks, word-level diff".

## Files likely touched

- `Cargo.toml` (workspace member)
- `crates/diff/**` (new, package `diff`)
- `docs/PLAN.md` (row 8 status)

## PRD law numbers

- 1: `apply(diff(a, b), a) == b`
- 2: `diff(a, a)` is empty
- 3: line numbers in every hunk map to real lines in both files

## Constraints

- Pure crate: no IO, clock, threads or randomness. The 200 ms budget is a work counter, not a timer.
- No dependencies except `proptest` (dev). Own Myers and histogram, no `similar` or `imara-diff`.
- Line endings are kept: `Eol::{Lf, CrLf, None}` is part of every line. `a\r\n` and `a\n` are different lines.
- Never panics on any input; `apply` returns an error for a diff that does not fit.

## Acceptance criteria

- `cargo test -p diff` passes, with property tests for laws 1, 2 and 3 over random texts (CRLF, missing final newline, unicode, many repeated lines), both algorithms and several context sizes.
- Myers is checked against an LCS oracle for minimal edit count; histogram output is checked for validity.
- Word diff has a property test (text outside the spans is identical on both sides).
- Each test is shown to fail on a planted bug; results are in DONE.md.
- A 50k-line file with about 2k changes diffs fast (generous bound in a test).
- `cargo xtask check` passes.

## Out of scope

- Line staging patches (task 11), tree-sitter highlighting (task 9), the viewer (task 10).
- File-level model (`FileDiff`, binary, generated), mode and submodule handling, hunk headers from tree-sitter, criterion benchmarks (task 25).
