# Task P0-1

## Goal

Prepare the Windows laptop and the repository for the Phase 0 GPUI spike: confirm the toolchain, create the Linux kernel fixture clone, and scaffold the two throwaway spike crates so each opens an empty GPUI window from a release build.

## Backlog task number

P0-1, the first of four Phase 0 tasks (P0-1 to P0-4). It covers Phase 0 setup steps 1–4 in [the plan](../docs/PLAN.md#phase-0--gpui-spike). It is not a v0.1 backlog row.

## Files likely touched

- `Cargo.toml`, `Cargo.lock`
- `spike-diff/`, `spike-graph/` (new crates)
- `scripts/` (fixture generator script)
- `.gitignore` (adds `fixtures/`)
- `README.md` (GPUI revision and why)
- `docs/PLAN.md` (reference-machine Windows build number)
- `docs/spike-results.md` (new: kernel clone record)
- `tasks/P0-1.DONE.md`

## PRD law numbers

None. Spike crates are throwaway and hold no product logic.

## Constraints

- Runs on the Windows laptop. Any crate may be built and launched, but the agent cannot see the window, so the user checks anything visual.
- Do not install anything without asking.
- The kernel clone lives outside this repo at `C:\dev\fixtures\linux` and is read-only after `git commit-graph write --reachable`.
- Release builds only, to save disk.
- GPUI comes from a git dependency on `zed-industries/zed`, pinned to one exact commit.
- No new dependencies beyond GPUI for this step.
- Until `cargo xtask check` works, run `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings` and `cargo test`.

## Steps

1. **Preflight.** Check and report, without installing anything:
   - Free disk space on the drive; warn if it is under 40 GB.
   - `rustc`, `cargo` and `rustup` versions; the default toolchain must be `x86_64-pc-windows-msvc`.
   - Visual Studio Build Tools with the C++ workload (the MSVC linker is found).
   - git ≥ 2.40.
   - The Windows build number, written into the reference-machine line of `docs/PLAN.md`.
   - If anything is missing, stop and say exactly what to install.
2. **Kernel fixture**, outside this repo:
   - In the background, clone `https://github.com/torvalds/linux.git` into `C:\dev\fixtures\linux` with `--filter=blob:none`, then go on to step 3.
   - When the clone finishes, run `git commit-graph write --reachable` there. Record the HEAD hash, its date and the clone path in `docs/spike-results.md`.
   - Treat the clone as read-only from then on.
3. **Scaffold the spike** (Phase 0 in `docs/PLAN.md`):
   - Add two throwaway binary crates, `spike-diff` and `spike-graph`, to the Cargo workspace.
   - Depend on GPUI as a git dependency on `zed-industries/zed`, pinned to one recent commit. Record the exact revision and why in `README.md`.
   - Add a fixture script that writes a 50k-line Rust-like file and a copy with about 2k changed lines spread through it into a gitignored `fixtures/` folder.
   - `cargo build --release -p spike-diff` and `cargo build --release -p spike-graph` both succeed, and each binary opens an empty window when run.
4. **Handoff.** Write `tasks/P0-1.DONE.md` with the GPUI revision, build times, the size of `target/`, anything that fought back, and a Windows checklist (exact commands and what the user should see). Commit, then stop.

## Acceptance criteria

- `cargo build --release -p spike-diff` and `cargo build --release -p spike-graph` succeed on Windows.
- `cargo run --release -p spike-diff` and `cargo run --release -p spike-graph` each open an empty window (the user verifies).
- The fixture script produces `fixtures/` files of 50,000 lines each, about 2,000 lines different, and git ignores `fixtures/`.
- `docs/spike-results.md` records the kernel HEAD hash, date and clone path. The commit-graph file exists in the clone.
- `README.md` records the GPUI revision and why it was chosen.
- `docs/PLAN.md` carries the real Windows build number.
- `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings` and `cargo test` pass.

## Out of scope

- Prototype A (diff view) and Prototype B (commit graph) rendering. Those are later Phase 0 tasks.
- Any measurement against the Phase 0 gate.
- Product crates (`core`, `diff`, `graph`, `ui`, `app`).
