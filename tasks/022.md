# Task 022

## Goal

Notes on lines of the pre-push review, kept in one SQLite file, with a warning on the push while to-dos are open; and, as the follow-up of task 12, the undo stack kept in the same file so it survives a restart.

## Backlog task number

22 in [the plan](../docs/PLAN.md#v01-backlog): "Notes and annotations: SQLite store (`rusqlite`, approved 2026-11-22), anchoring, to-do warning on push; also persists the undo stack (task 12 follow-up)".

## Files likely touched

- `crates/core/src/notes.rs` (new, pure): the note, the anchor, cleaning a body, finding a line again.
- `crates/shell/src/store.rs` (new): the SQLite file; `crates/shell/Cargo.toml`, `Cargo.toml` (`rusqlite`).
- `crates/app/src/{notes_db,review,review_view,persist}.rs`
- `docs/PLAN.md` (row 22)

## PRD law numbers

- "Notes are local and private, stored per repo and anchored to commit + file + line, so they survive rebases where possible"; "a note can be marked as a to-do; push shows a warning when unresolved to-dos remain"; "one database in the app data folder, never inside `.git`" (PRD build-vs-library table).
- Rule 1: the core stays pure (no clock, no IO): the time comes from the shell, the file from `shell`.

## Constraints

- `rusqlite` is approved (2026-11-22) and is added here, built from source (`bundled`), nothing else new.
- Tests use generated repos and temp folders; never the user's data folder.

## Acceptance criteria

- Property tests for the anchoring (a line is found where it moved, the nearest of equal lines wins, no line outside the file is returned) and for the store (any text round-trips, SQL in a text does nothing, a note is only reachable through its own repo, a newer file is refused).
- A run in the real app: add a to-do note on a line of the review, see the warning, restart, see the note, rewrite the commit and see the note follow, resolve it and see the warning go.
- `cargo xtask check`; a Windows checklist in `022.DONE.md`.

## Out of scope in this part

- Notes drawn inside the diff, editing a note's text, notes outside the review (the Changes and History pages).
