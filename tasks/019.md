# Task 019

## Goal

The commit detail view beside the commit graph: pick a commit and see its message, author, date and parents, the files it changed, and the diff of the chosen file in the diff viewer (read only).

## Backlog task number

19 in [the plan](../docs/PLAN.md#v01-backlog): "Commit detail view with its diff" (UI). Depends on 10 (diff viewer) and 18 (graph, `GraphEvent::Selected`).

## Files likely touched

- `crates/shell/src/{commit_detail,staging,lib}.rs`, `crates/shell/tests/commit_detail.rs` (new)
- `crates/ui/src/{commit_detail,time,lib}.rs`
- `crates/app/src/{commit_pane,history_view,repo_view,main}.rs`
- `docs/PLAN.md` (row 19), `tasks/019.DONE.md`

## PRD law numbers

None of the 14 laws is about reading history. Rules that apply: pure `core`/`diff`/`graph`, IO only in `shell` (rule 2), reads through gix (rule 3), UI only renders state and sends events (rule 7), colours and sizes from `tokens`.

## Constraints

- The commit and the file sides are read in `shell` through gix, off the UI thread; an answer for a commit or file that is no longer chosen is dropped.
- A root commit is compared with the empty tree; a merge against its first parent, and the panel says so.
- No new dependencies; no rename detection in this task (a rename shows as a delete and an add).
- The diff is read only: no staging controls.

## Acceptance criteria

- `cargo test -p shell --test commit_detail`: the listing agrees with `git diff-tree` on random histories; root, merge, empty commit, binary, non-UTF-8, unicode paths, unknown commit.
- `cargo test -p ui` (message split, short hash, date with offset) and `cargo test -p app`.
- `cargo xtask check` passes. A Windows checklist is in `019.DONE.md`.

## Out of scope

Rename detection, a combined diff for merges, jumping to a parent from the panel, a "not on origin yet" status, copying more than the hash, opening a commit from the changes page.
